# Реверси (Reversi)

Консольная игра «Реверси», написанная на Python. Проект был сделан в рамках учебного задания(вроде в 24 году) с применением подхода TDD (Test-Driven Development) и использованием тестовых двойников.

## Возможности

* Поддерживаемые режимы игры (`local`, `bot`, `remote`). В режиме `remote` используется сервер-заглушка.


* Настраиваемый размер игрового поля через JSON-файл настроек или аргументы командной строки.


* Логирование всех ключевых событий и ходов в отдельный файл.


* Полное покрытие функционала модульными, интеграционными и системными тестами (`unittest`, `pytest`, `subprocess`).



## Запуск проекта

Для запуска игры используется главный скрипт `main.py`.

Пример запуска с аргументами командной строки:

```bash
python main.py --mode bot --size 8

```

### Доступные аргументы командной строки

:

* `--mode` — выбор режима игры (`local` — игрок против игрока, `bot` — против бота, `remote` — против удалённого игрока через сервер-заглушку).


* `--settings` — путь к JSON-файлу с настройками (по умолчанию `settings.json`).


* `--size` — размер игрового поля, который переопределяет настройки из файла.


* `--logfile` — имя файла для записи логов (по умолчанию `game.log`).



Во время игры в консоли запрашиваются координаты хода в формате `строка столбец` через пробел.

## Архитектура и структура проекта

Проект разбит на несколько модулей:

* `main.py` — точка входа, парсинг аргументов командной строки и инициализация игрового процесса.


* `game/board.py` — логика игрового поля, проверка валидности ходов, перевороты фишек по всем 8 направлениям и подсчёт очков.


* `game/play.py` — высокоуровневая игровая механика, чередование ходов, проверка окончания партии и обработка пропуска ходов.


* `game/player_bot.py` — реализация простого бота (`RandomBot`), выбирающего случайные доступные ходы.


* `game/logger_config.py` — настройка и инициализация логирования.


* `settings.py` — загрузка и валидация конфигурации из файла `settings.json`.
